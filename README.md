# Kampala Fuel Price Predictor

This project contains data and notebooks for analyzing and predicting fuel
prices in Kampala, Uganda.

## Project structure

- `data/raw/` - source datasets used for analysis
- `data/processed/` - processed datasets generated by the analysis
- `notebooks/` - Jupyter notebooks for exploration and modeling

## Data sources

The raw data includes:

- Brent crude oil weekly prices
- Uganda fuel prices published by UBOS
- Uganda fuel tax rates
- USD/UGX exchange rates

## Getting started

Open the notebooks in `notebooks/` with Jupyter or VS Code and use the files
in `data/raw/` as inputs.
