# Kampala Fuel Price Predictor

This project contains data and notebooks for analyzing and predicting fuel
prices in Kampala, Uganda.

## Project structure

- `data/raw/` - source datasets used for analysis
- `data/processed/` - processed datasets generated by the analysis
- `notebooks/` - Jupyter notebooks for exploration and modeling

## Data sources

The raw data includes:

- Brent crude oil weekly prices
- Uganda fuel prices published by UBOS
- Uganda fuel tax rates
- USD/UGX exchange rates

## Getting started

Install the notebook dependencies into the interpreter selected by VS Code:

```powershell
python -m pip install -r requirements.txt
```

Then open the notebooks in `notebooks/` with Jupyter or VS Code and use the
files in `data/raw/` as inputs. If VS Code still reports a dead kernel, select
the same interpreter where the dependencies were installed:

1. Open the Command Palette (`Ctrl+Shift+P`).
2. Run **Python: Select Interpreter**.
3. Choose the interpreter used for the installation above.
4. Restart the notebook kernel.
